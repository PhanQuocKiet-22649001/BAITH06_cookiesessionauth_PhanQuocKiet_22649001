Chạy file app.js: node app.js

- Đăng ký tài khoảng với route "/register" với phương thức POST và http://localhost:3000/auth/register tại POSTMAN
- Nhập username và password: 
{
  "username": "testuser",
  "password": "123456"
}
sau đó nhấn Send. kết quả trả về là "message": "User registered successfully!"
